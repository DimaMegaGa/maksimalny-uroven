# Проверка локальной и HTTPS-версий — 30 октября 2026

## Исправления

- HTML-ответы посредника вместо JSON больше не показывают пользователю английские
  ошибки парсера, включая Safari «The string did not match the expected pattern».
  Для API Serveo передаётся документированный заголовок пропуска его уведомления.
  Добавлены ограничение времени ожидания и понятные сообщения при потере связи.
- Устранена гонка между фоновым обновлением и сохранением изменений. Устаревший
  ответ обновления больше не восстанавливает предыдущий сеанс после выхода.
- Разделены cookie локальных копий на разных портах. Вход в копию показа
  больше не перезаписывает сеанс основного сайта на 8765/8767.
- Загрузка аватарки показывает состояние и подтверждение сохранения, блокирует
  повторную отправку, поддерживает файлы с пустым MIME по расширению и не превращает
  прозрачность PNG в чёрный фон при преобразовании в JPEG.
- Иконки 23 предметов в обмене и карточках используют те же файлы и размер 32×32.
- Переход из карточки предмета сохраняет выбранный предмет вместо сброса фильтра.
- Отклонённые работы доступны отдельной вкладкой. Учитель может просмотреть
  подтверждённую работу без повторного начисления баллов.
- Комментарий учителя сохраняется при открытии фотографии и возврате к проверке.
- Число выполненных заданий в чужом профиле берётся из серверного агрегата,
  а не из неполного списка работ, доступного текущему участнику.
- Приветствия используют имя из ФИО. Обработаны ошибки сохранения уведомлений.
- Изменение CSV-формы министерства инвалидирует проверку; запоздалый ответ
  проверки старой таблицы не разрешает создать пакет с изменёнными данными.
- Обновлены версии ресурсов HTML для получения исправленных JS/CSS.

## Что проверено

- `node --check` для всех трёх JS-файлов; синтаксический разбор всех CSS без ошибок.
- `node tests/test-client.cjs`: JSON/HTML и Safari-ошибка, тайм-аут, заголовок Serveo,
  фильтр предметов, MIME изображения и фон прозрачной аватарки.
- `python backend/test_container.py`: 7 тестов, включая роли, импорт и пакеты,
  начисление и обмен баллов, сохранение аватарки и проверку внешнего Origin.
- В браузере: отправка работы учеником, подтверждение учителем, награда +25,
  запрос обмена и подтверждение списания 25 баллов.
- Через HTTPS: доработка, подтверждение, начисление и списание 30 баллов за математику;
  сохранение аватарки и её восстановление после перезагрузки страницы.
- Побайтовое сравнение 33 открытых ресурсов: локальная и HTTPS-версии совпадают.
- 28 проверок семи страниц на ширинах 320, 390, 768 и 1280: горизонтального переполнения
  документа и сломанных изображений не найдено. Проверены одинаковые источники и
  размеры всех 23 иконок в предметах и обмене.

## Практические ограничения

Проверки действий выполнялись с вымышленными участниками в отдельной базе.
Основная база сохранена; разные списки пользователей и задания не означают
разный код интерфейса.

Реальный iPhone/Safari удалённо не проверялся: проверен сценарий той же ошибки
парсера и браузерные сценарии в Chromium. Нельзя гарантировать отсутствие любых
ошибок на всех устройствах по этим проверкам.

Бесплатный Serveo завершает туннели по сроку действия; это видно в его журнале.
После завершения старый адрес недоступен. Обработка ответа исправлена, но это
не продлевает туннель. Для постоянной доступности нужен постоянный хостинг.
Текущие ссылки находятся только локально в `runtime/showcase/status.json`.
