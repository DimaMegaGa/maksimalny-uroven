# Размещение на alwaysdata

Готовая школьная платформа: https://maksimalny-uroven-30d.alwaysdata.net/.
Портал министерства: https://maksimalny-uroven-30d.alwaysdata.net/ministry/.

Для проверки этой версии достаточно открыть ссылки и воспользоваться доступами из файла для жюри. Инструкция ниже нужна только для самостоятельного размещения.

## Своя установка

1. Загрузите содержимое папки проекта в отдельный каталог аккаунта alwaysdata.
2. Создайте виртуальное окружение с Python 3.11+ и установите `requirements.txt`.
3. В настройках сайта выберите Python WSGI. Точка входа — `deployment/wsgi_entry.py`, рабочая папка — корень проекта. Укажите путь к виртуальному окружению.
4. Задайте `MAKS_PUBLIC_ORIGIN=https://ВАШ-ДОМЕН` без пути и `MAKS_SECURE_COOKIE=1`.
5. При запуске точка входа создаст отдельный каталог `runtime`, SQLite и ключ хранилища.
6. Школьный адрес — `https://ВАШ-ДОМЕН/`, министерство — `https://ВАШ-ДОМЕН/ministry/`.
7. Для CLI-команд создания доступов задайте `MAKS_DB_PATH` равным абсолютному пути `runtime/maks.sqlite3`, а `MAKS_VAULT_KEY_FILE` — пути `runtime/vault.key` этой установки. Используйте тот же виртуальный Python и команды из README.

Не настраивайте открытый статический доступ ко всему каталогу проекта. Приложение само выдаёт разрешённые ресурсы и проверяет доступ к данным.

## MAX

Подключение бота описано в `docs/MAX.md`. Для доставки уведомлений нужен запуск `scripts/deliver_max_notifications.py` планировщиком; на опубликованной версии настроен запуск раз в минуту. У своей установки должны быть собственные конфигурация и секрет webhook.

Существующий токен бота, рабочие данные и ключи сервера в архив не включены.
