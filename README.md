# МАКСимальный Уровень

Школьная платформа в MAX. Учитель публикует задания и проверяет работы, ученик получает баллы и достижения. Ученик может отправить запрос на обмен баллов на оценку, который рассматривает учитель. Отдельный портал министерства подготавливает учётные записи по спискам CSV/XLSX и отправляет пакеты директору.

Проект поддерживает инициативу учеников и помогает учитывать участие в школьной жизни. Задания, результаты проверки и достижения создают поводы возвращаться в мини-приложение. Влияние на мотивацию и активность пользователей предстоит измерить в школьном пилоте. [Замысел проекта и планы развития](docs/PROJECT.md).

## Проверить опубликованную версию

- [Бот и мини-приложение MAX](https://max.ru/ideya_fiks_30_bot). Нажмите «Начать», затем «Открыть платформу».
- [Школьная платформа в браузере](https://maksimalny-uroven-30d.alwaysdata.net/).
- [Портал министерства](https://maksimalny-uroven-30d.alwaysdata.net/ministry/).

В личном чате бот поддерживает `/start`, `/help`, `/status`, `/about` и `/stop`. В профиле школьной учётки можно подключить уведомления MAX. Подключение подтверждается в нужном аккаунте MAX через бота. Доставка школьных уведомлений обычно занимает до минуты.

Коды из ZIP предназначены для опубликованного сайта. Доступ к демо-кодам получает жюри через приватный репозиторий. При самостоятельном запуске создаются своя база и новые учётки по инструкции ниже.

Короткий сценарий проверки опубликованной версии.

1. Войдите учеником и откройте условия задания. Отправьте ответ, при необходимости добавьте фото.
2. Войдите учителем и проверьте работу. Примите результат или верните его на доработку с комментарием.
3. У ученика проверьте историю, решение учителя и баланс. За принятую работу начисляются баллы.
4. Отправьте запрос на обмен по предмету учителя. После одобрения учителем баллы списываются. Оценку учитель выставляет отдельно.
5. В профиле подключите уведомления MAX и проверьте доставку. Каждый участник подтверждает привязку в своём аккаунте MAX.
6. В министерстве загрузите список, проверьте строки, создайте пакет и отправьте его директору. В кабинете директора проверьте входящие списки.

## Готовый Docker-образ

[Релиз jury-v1.0.1](https://github.com/DimaMegaGa/maksimalny-uroven/releases/tag/jury-v1.0.1) содержит файл `maks-level-image.tar.gz`. Он собран и проверен в GitHub Actions. Для приватного репозитория владелец должен выдать жюри доступ к исходникам и релизу.

Нужны Docker и Compose v2. Скачайте образ из релиза и исходники проекта. Откройте терминал в папке с `compose.yaml`, поместите скачанный файл в эту же папку и выполните команды.

```sh
docker load -i maks-level-image.tar.gz
docker tag maks-level:submission maks-level:demo-alwaysdata
docker compose up -d --no-build --wait
docker compose ps
```

Docker читает сжатый файл напрямую. Дополнительное имя `maks-level:demo-alwaysdata` соответствует образу в `compose.yaml`.

| Портал | Локальный адрес |
|---|---|
| Школа для ученика, учителя и директора | http://127.0.0.1:19111/ |
| Министерство | http://127.0.0.1:19112/ |

Создайте первые доступы в запущенных контейнерах.

```sh
docker compose exec school python backend/manage_access.py create-director --school "Школа проверки" --label "Директор"
docker compose exec ministry python backend/manage_ministry.py create --label "Оператор министерства"
```

Сохраните показанные коды. Затем выполните импорт учеников и учителей, описанный в разделе «Создать учётки».

Остановка выполняется командой `docker compose down`. База и ключ шифрования сохраняются в томе `maks-data`.

## Собрать Docker-образ из исходников

Из папки проекта выполните команды.

```sh
docker compose build
docker compose up -d --wait
docker compose ps
```

Оба портала открываются по адресам из таблицы выше. Команды создания доступов совпадают с командами для готового образа.

Пример сборки и запуска одного контейнера школьного сайта из командной строки.

```sh
docker build -t maks-level:submission .
docker run --rm --name maks-school -p 127.0.0.1:19111:8765 -v maks-data:/data maks-level:submission
```

Экспорт и загрузка образа на другом компьютере.

```sh
docker save -o maks-level-image.tar maks-level:submission
docker load -i maks-level-image.tar
```

Архив исходников содержит Dockerfile и Compose. Готовый образ распространяется отдельным файлом в релизе GitHub.

## Запуск через Python на Windows

Нужен Python 3.11 или новее. Откройте терминал в папке проекта.

```sh
python -m pip install -r requirements.txt
python start.py
```

После установки зависимостей можно запускать `start.cmd` двойным щелчком. Школа открывается на порту 19111, министерство на порту 19112.

```sh
python start.py --no-browser
python stop.py
```

Для резервной копии предусмотрен `backup.cmd`. Авторизация работает при открытии сайта через Python-сервер. Для Linux/macOS используйте описанный выше Docker-запуск с переносимым ключом шифрования.

## Создать учётки

При запуске через Python откройте новый терминал в папке проекта и выполните команды.

```sh
python backend/manage_access.py create-director --school "Школа проверки" --label "Директор"
python backend/manage_ministry.py create --label "Оператор министерства"
```

При запуске через Docker используйте команды с `docker compose exec` из раздела о готовом образе.

1. Сохраните показанные коды директора и министерства.
2. Откройте портал министерства и войдите по его коду.
3. Выберите организацию и директора, загрузите `templates/roster-template.csv`, проверьте строки и создайте пакет.
4. Отправьте пакет директору. После отправки учётные записи учеников и учителей активируются.
5. У директора откройте входящий пакет. В нём доступны ФИО и персональные коды для входа участников на школьном сайте.

[Подробная инструкция по доступам и спискам](docs/ACCESS.md).

## Структура проекта

| Папка или файл | Назначение |
|---|---|
| `frontend/` | Интерфейс, стили, изображения и MAX Bridge |
| `backend/` | Python API, SQLite, роли, задания, баллы и бот |
| `templates/` | Шаблон списка для импорта |
| `tests/`, `backend/test_*.py` | Проверки на отдельных временных данных |
| `scripts/` | Уведомления, настройка команд бота, экспорт и упаковка |
| `deployment/` | Размещение на сервере |
| `docs/` | Замысел, доступы, архитектура и интеграция MAX |
| `Dockerfile`, `compose.yaml` | Сборка и запуск двух порталов |
| `requirements.txt` | Библиотеки Python с версиями |

Рабочая база и закрытые настройки создаются при запуске. Для собственной копии бота настройте собственные конфигурацию и ключи. Владелец опубликованной версии хранит её базу и секреты на сервере alwaysdata.

## Размещение и интеграции

Опубликованная версия размещена на alwaysdata. Для уведомлений собственной установки нужны бот MAX, приватная конфигурация, HTTPS webhook и планировщик доставки. [Инструкция размещения](deployment/CASE.md).

Кабинет министерства демонстрирует централизованную выдачу доступов. Прямая интеграция со Сферумом, государственными реестрами и электронным журналом относится к возможным направлениям развития. В текущей версии реализованы мини-приложение MAX, бот и его уведомления.
